# MS Access
This folder contains screenshots and project files for the MS Access database portion of the business analytics project.
## Project Summary
This project involved building and customizing a warehouse operations database in Microsoft Access using employee and warehouse activity data. The database supports structured data entry, lookup relationships, calculated fields, validation rules, conditional formatting, form navigation, and query-based reporting.

## Key Tasks Completed
- Imported employee data from Excel into the EmployeeDATA table.
- Created lookup tables for Rating, Customer, Part, and Distribution Centre fields.
- Linked Customer, Part, DC, and Picker fields to the appropriate warehouse activity and employee data tables.
- Created and customized the WarehouseACTIVITY form with all related fields, layout changes, option buttons, and navigation controls.
- Added validation rules and formatting for Order Date, Revenue, COGS, Quantity, and Profit Margin.
- Created a calculated Profit Margin field to analyze revenue and cost performance.
- Added command buttons for next record, previous record, save, add new record, and related picker lookup.
- Applied conditional formatting to highlight revenue values below defined thresholds.
- Built queries for large orders, warehouse/customer filtering, and USD revenue conversion.
- Updated database startup settings, including application title, display form, and compact-on-close.
