## Tableau Project Description
Developed an interactive Tableau dashboard using a coursework employee and production dataset with 350+ records. The dashboard includes 8 visuals to analyze employee and production performance. The dashboard highlights trends in salary distribution, absenteeism, efficiency, units made, rejected units, performance ratings, and employee distribution across departments and countries.
## Key Features
-Built an interactive Tableau dashboard with 8 different visuals to analyze employee and production performance.
-Created visualizations for salary distribution, performance ratings, absenteeism, employee location, efficiency, units made, and rejected units.
-Used filters to allow users to explore the dashboard by country, department, and other categories.
-Designed charts to compare productivity and efficiency across different departments and employee groups.
-Used scatter plots and bar charts to identify relationships between absent days, net units, and productivity.
-Included a map visualization to show employee distribution across countries such as Canada, USA, and Mexico.
-Organized the dashboard layout to make insights easy to read and understand.
