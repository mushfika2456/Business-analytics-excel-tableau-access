# MS Access

## MS Access Project Summary
This project involved building and customizing a warehouse operations database in Microsoft Access using employee and warehouse activity data. The database supports structured data entry, lookup relationships, calculated fields, validation rules, conditional formatting, form navigation, and query-based reporting.

## MS Access - Key Tasks Completed
- Imported employee data from Excel into the EmployeeDATA table.
- Created lookup tables for Rating, Customer, Part, and Distribution Centre fields.
- Linked Customer, Part, DC, and Picker fields to the appropriate warehouse activity and employee data tables.
- Created and customized the WarehouseACTIVITY form with all related fields, layout changes, option buttons, and navigation controls.
- Added validation rules and formatting for Order Date, Revenue, COGS, Quantity, and Profit Margin.
- Created a calculated Profit Margin field to analyze revenue and cost performance.
- Added command buttons for next record, previous record, save, add new record, and related picker lookup.
- Applied conditional formatting to highlight revenue values below defined thresholds.
- Built queries for large orders, warehouse/customer filtering, and USD revenue conversion.
- Updated database startup settings, including application title, display form, and compact-on-close.

## Tableau - Project Description
Developed an interactive Tableau dashboard using a coursework employee and production dataset with 350+ records. The dashboard includes 8 visuals to analyze employee and production performance. The dashboard highlights trends in salary distribution, absenteeism, efficiency, units made, rejected units, performance ratings, and employee distribution across departments and countries.
## Tableau - Key Tasks Completed
- Built an interactive Tableau dashboard with 8 different visuals to analyze employee and production performance.
- Created visualizations for salary distribution, performance ratings, absenteeism, employee location, efficiency, units made, and rejected units.
- Used filters to allow users to explore the dashboard by country, department, and other categories.
- Designed charts to compare productivity and efficiency across different departments and employee groups.
- Used scatter plots and bar charts to identify relationships between absent days, net units, and productivity.
- Included a map visualization to show employee distribution across countries such as Canada, USA, and Mexico.
- Organized the dashboard layout to make insights easy to read and understand.
